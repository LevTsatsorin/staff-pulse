## ADDED Requirements

### Requirement: Поток изменений
Сервер ДОЛЖЕН принимать WebSocket-соединения на `/ws`, отправлять `hello` с текущей версией и рассылать патчи всем подключённым клиентам. Тикер меняет случайный узел каждые 1–3 с (интервал настраивается через `PATCH_INTERVAL_MS`), периодически — пачку из 2–4 узлов. Каждый патч увеличивает версию, которая совпадает с `ETag` снапшота.

#### Scenario: Подключение
- **WHEN** клиент открыл `/ws`
- **THEN** первым сообщением получает `hello` с версией, равной `ETag` текущего снапшота

#### Scenario: Рассылка
- **WHEN** тикер изменил узел
- **THEN** все подключённые клиенты получают одинаковый `patch`, а последующий `GET /api/org-tree` отдаёт обновлённые значения и новый `ETag`
