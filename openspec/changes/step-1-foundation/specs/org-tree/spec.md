## Purpose

Интерактивное дерево орг-структуры: навигация по дивизионам, отделам и командам с ключевыми показателями каждого узла.

## ADDED Requirements

### Requirement: Раскрытие и скрытие ветвей
Каждый узел с потомками ДОЛЖЕН раскрываться и скрываться кнопкой-шевроном; по умолчанию раскрыты корневые узлы, так что видны дивизионы и их отделы, а команды скрыты.

#### Scenario: Начальное состояние
- **WHEN** данные загружены
- **THEN** все корни раскрыты, их дети видны и свёрнуты

#### Scenario: Переключение ветви
- **WHEN** пользователь нажимает шеврон свёрнутого узла
- **THEN** его дети показываются; повторное нажатие скрывает их; клик по названию узла ветвь не сворачивает

#### Scenario: Состояние переживает обновление данных
- **WHEN** данные обновились фоновым запросом
- **THEN** набор раскрытых узлов не сбрасывается

### Requirement: Содержимое узла
Узел ДОЛЖЕН показывать название, собственный `headcount` и цветовой индикатор `performance` (три тона по порогам) с числовым значением и текстовой подписью для доступности.

#### Scenario: Тон индикатора
- **WHEN** у узла performance 45, 65 и 85
- **THEN** индикатор окрашен в тон low, mid и high соответственно и содержит текст «45%», «65%», «85%»

#### Scenario: Доступность индикатора
- **WHEN** индикатор отрисован
- **THEN** у него есть `aria-label` вида «Эффективность 73%»

### Requirement: Состояния данных
Дерево ДОЛЖНО различать состояния: загрузка (skeleton), ошибка (сообщение + «Повторить»), пустой ответ («Структура пуста»), успех.

#### Scenario: Загрузка
- **WHEN** запрос выполняется впервые
- **THEN** показан skeleton той же высоты, что и строки дерева

#### Scenario: Ошибка
- **WHEN** запрос завершился ошибкой сети, сервера или валидации
- **THEN** показано человекочитаемое сообщение и кнопка «Повторить», которая повторяет запрос

#### Scenario: Пустой ответ
- **WHEN** сервер вернул `[]`
- **THEN** показано пустое состояние «Структура пуста» без признаков ошибки

### Requirement: Семантика и стилизация
Дерево ДОЛЖНО быть размечено как `role="tree"` / `role="treeitem"` с `aria-expanded` и `aria-level`; стилизация выполняется через styled-components без атрибута `style`.

#### Scenario: Проверка разметки
- **WHEN** выполняется поиск `style=` по `src/`
- **THEN** совпадений нет, у узлов присутствуют роли и aria-атрибуты
