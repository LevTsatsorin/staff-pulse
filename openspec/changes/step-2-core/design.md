## Context

Модель из этапа 01 лежит в кэше TanStack Query. Требования 02: агрегаты «считаются один раз и мемоизируются», сортировка кликом / обратная двойным, дебаунс 250 мс, формат `12 345 678 руб.`, связь строка ↔ узел. Этап 03 потребует инкрементального пересчёта, поэтому структура агрегатов выбирается уже сейчас.

## Goals / Non-Goals

**Goals:** агрегаты в модели, таблица как настоящий `<table>`, чистые функции сортировки/фильтра с тестами, двусторонняя связь с деревом.

**Non-Goals:** keyboard navigation, fade обновлённых ячеек, виртуализация (52 строки).

## Decisions

- **Агрегаты — часть `OrgModel`, считаются в `buildOrgModel`.** `aggregates[id] = { totalHeadcount, totalBudget, perfWeightedSum, avgPerformance }`; `avgPerformance = perfWeightedSum / totalHeadcount` или `null`. Хранить `perfWeightedSum` отдельно нужно, чтобы на 03 пересчитывать предка из прямых детей без повторного обхода поддерева. Альтернатива — `useMemo` от сырого массива — пересчитывает всё при каждом патче. → ADR-002.
- **Пайплайн строк — цепочка чистых функций** `toTableRows(model)` → `filterRows(rows, query)` → `sortRows(rows, sort)`, каждая в своём `useMemo` внутри `useTableRows`. `toTableRows` зависит только от модели, поэтому фильтр и сортировка её не трогают.
- **Сортировка:** локальное состояние `{ key, direction }` в `useSortState`; компаратор на столбец; `null` всегда в конце независимо от направления; строки — `localeCompare('ru')`. Обработка `click` идемпотентна, `dblclick` переключает — потому что `dblclick` всегда приходит после двух `click`.
- **Фильтр:** `useDebouncedValue(query, SEARCH_DEBOUNCE_MS)`; сравнение через `toLocaleLowerCase('ru')`; подсветка `<mark>` через утилиту `splitByMatch`.
- **Формат денег:** `Intl.NumberFormat('ru-RU')` создаётся один раз на модуль; тест проверяет U+00A0 как разделитель групп.
- **`SelectionProvider`** держит `selectedId` и `expandedIds` (Set) — оба переживают патчи, фильтр и переключение представлений. Данных в контексте нет: единственный источник — кэш. `useRevealNode(model)` = выбрать + раскрыть предков; прокрутка — эффект внутри `OrgTreeNode` по `isSelected`.
- **Раскладка:** `useMediaQuery('(min-width: 1280px)')` через `matchMedia`; при узком экране неактивное представление не размонтируется, а скрывается (`hidden`), чтобы не терять DOM-состояние прокрутки; логическое состояние всё равно в провайдере.
- **Строки таблицы — `React.memo(OrgTableRow)`** с примитивными пропсами (`row`, `isSelected`, `query`), чтобы на 03 патч перерисовывал только затронутые строки.

## Risks / Trade-offs

- [Путь родителей в ячейке названия делает строку высокой] → две строки текста, `line-height` компактный; на узких экранах путь скрывается.
- [`dblclick` недоступен с клавиатуры] → Enter/Space на активном заголовке обращает направление, описано в README.
- [`localeCompare` медленный на больших данных] → 52 строки; при росте — `Intl.Collator` один раз на модуль.
