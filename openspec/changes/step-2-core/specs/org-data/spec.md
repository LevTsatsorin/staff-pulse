## ADDED Requirements

### Requirement: Агрегаты в модели
Нормализованная модель ДОЛЖНА содержать для каждого узла агрегат: суммарный headcount, суммарный бюджет, взвешенную сумму performance × headcount и среднюю эффективность (`null`, если суммарный headcount 0). Агрегаты считаются один раз при построении модели.

#### Scenario: Лист
- **WHEN** узел без детей имеет headcount 10, бюджет 100, performance 70
- **THEN** его агрегат равен собственным значениям, средняя эффективность 70

#### Scenario: Вложенность
- **WHEN** дивизион содержит отделы, содержащие команды
- **THEN** агрегат дивизиона включает собственные значения дивизиона, отделов и команд

#### Scenario: Пустое дерево
- **WHEN** ответ API — `[]`
- **THEN** модель строится без ошибок с пустыми коллекциями
