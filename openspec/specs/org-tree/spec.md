# org-tree Specification

## Purpose
Интерактивное дерево орг-структуры: навигация по дивизионам, отделам и командам с ключевыми показателями каждого узла.

## Requirements

### Requirement: Раскрытие и скрытие ветвей
Каждый узел с потомками ДОЛЖЕН раскрываться и скрываться кнопкой-шевроном; по умолчанию раскрыты корневые узлы, так что видны дивизионы и их отделы, а команды скрыты.

#### Scenario: Начальное состояние
- **WHEN** данные загружены
- **THEN** все корни раскрыты, их дети видны и свёрнуты

#### Scenario: Переключение ветви
- **WHEN** пользователь нажимает шеврон свёрнутого узла
- **THEN** его дети показываются; повторное нажатие скрывает их; клик по названию узла ветвь не сворачивает

#### Scenario: Состояние переживает обновление данных
- **WHEN** данные обновились фоновым запросом
- **THEN** набор раскрытых узлов не сбрасывается

### Requirement: Содержимое узла
Узел ДОЛЖЕН показывать название, суммарную численность поддерева и цветовой индикатор средней эффективности поддерева (взвешенной по численности; три тона по порогам) с числовым значением и текстовой подписью для доступности. Собственные значения узла ДОЛЖНЫ быть доступны в подсказке.

#### Scenario: Тон индикатора
- **WHEN** средняя эффективность поддерева 45, 65 и 85
- **THEN** индикатор окрашен в тон low, mid и high соответственно и содержит текст «45%», «65%», «85%»

#### Scenario: Суммы по поддереву
- **WHEN** у дивизиона собственный состав 5 чел., а в отделах и командах ещё 42
- **THEN** строка дивизиона показывает «47 чел.», подсказка — «В самом дивизионе: 5 чел., …» (название уровня по глубине: дивизион / отдел / команда)

#### Scenario: Нулевая численность
- **WHEN** суммарная численность поддерева 0
- **THEN** индикатор показывает «—» нейтральным тоном

#### Scenario: Доступность индикатора
- **WHEN** индикатор отрисован
- **THEN** у него есть `aria-label` вида «Эффективность 73%»

### Requirement: Состояния данных
Дерево ДОЛЖНО различать состояния: загрузка (skeleton), ошибка (сообщение + «Повторить»), пустой ответ («Структура пуста»), успех.

#### Scenario: Загрузка
- **WHEN** запрос выполняется впервые
- **THEN** показан skeleton той же высоты, что и строки дерева

#### Scenario: Ошибка
- **WHEN** запрос завершился ошибкой сети, сервера или валидации
- **THEN** показано человекочитаемое сообщение и кнопка «Повторить», которая повторяет запрос

#### Scenario: Пустой ответ
- **WHEN** сервер вернул `[]`
- **THEN** показано пустое состояние «Структура пуста» без признаков ошибки

### Requirement: Направляющие вложенности
Каждый уровень вложенности ДОЛЖЕН быть визуально отмечен направляющей (линия и подсветка колонки отступа) своего цвета, чтобы при большом числе раскрытых ветвей глубина читалась без подсчёта отступов.

#### Scenario: Три уровня раскрыты
- **WHEN** раскрыты дивизион и его отдел
- **THEN** под колонкой шеврона дивизиона видна направляющая первого цвета, под колонкой шеврона отдела — второго

### Requirement: Семантика и стилизация
Дерево ДОЛЖНО быть размечено как `role="tree"` / `role="treeitem"` с `aria-expanded` и `aria-level`; стилизация выполняется через styled-components без атрибута `style`.

#### Scenario: Проверка разметки
- **WHEN** выполняется поиск `style=` по `src/`
- **THEN** совпадений нет, у узлов присутствуют роли и aria-атрибуты

### Requirement: Выделение узла
Клик по названию узла ДОЛЖЕН выделять его (`aria-selected`), выделение синхронно с таблицей. При выборе узла извне дерево ДОЛЖНО раскрыть его предков и прокрутить узел в видимую область, без плавной прокрутки при `prefers-reduced-motion`.

#### Scenario: Клик по узлу
- **WHEN** пользователь кликает по названию команды в дереве
- **THEN** узел выделен, соответствующая строка таблицы подсвечена

#### Scenario: Выбор из таблицы
- **WHEN** узел выбран кликом по строке таблицы, а его предки свёрнуты
- **THEN** предки раскрыты, узел выделен и прокручен в видимую область

### Requirement: Анимация раскрытия
Раскрытие и скрытие ветви ДОЛЖНО анимироваться изменением высоты без inline-стилей; свёрнутое содержимое недоступно для фокуса; при `prefers-reduced-motion: reduce` анимация отключена.

#### Scenario: Раскрытие
- **WHEN** пользователь раскрывает узел
- **THEN** дети появляются с плавным ростом высоты (~200 мс), атрибут `style` в DOM не появляется

#### Scenario: Свёрнутая ветвь и Tab
- **WHEN** ветвь свёрнута и пользователь идёт по Tab
- **THEN** фокус не попадает в скрытые узлы

#### Scenario: Reduced motion
- **WHEN** в системе включено уменьшение движения
- **THEN** ветвь раскрывается мгновенно

### Requirement: Клавиатурная навигация по дереву
Дерево ДОЛЖНО иметь одну tab-остановку (roving tabindex на `treeitem`): ↑/↓ перемещают фокус по видимым узлам, Home/End — на первый и последний видимый, → раскрывает свёрнутую ветку или переходит к первому ребёнку раскрытой, ← сворачивает раскрытую ветку или переходит к родителю, Enter и Space выделяют узел. Кнопки внутри узлов остаются кликабельными, но не входят в порядок Tab. Если выделенный узел виден, Tab попадает на него.

#### Scenario: Раскрытие стрелкой
- **WHEN** фокус на свёрнутом отделе и пользователь нажимает →
- **THEN** отдел раскрывается, фокус остаётся на нём; повторное → переводит фокус на первую команду

#### Scenario: Сворачивание и подъём
- **WHEN** фокус на команде и пользователь нажимает ←
- **THEN** фокус переходит на отдел; ещё одно ← сворачивает отдел

#### Scenario: Одна tab-остановка
- **WHEN** пользователь идёт по Tab через страницу
- **THEN** внутри дерева ровно одна остановка, и это выделенный узел, если он виден
