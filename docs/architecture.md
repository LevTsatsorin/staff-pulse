```

│ pages/            DashboardPage — только композиция   │
```

Правило: логика в хуках и утилитах, разметка в компонентах, страница только собирает. Компоненты не знают про транспорт; хуки не знают про разметку.

## Поток данных: от API до UI

1. `useOrgTree` вызывает `useQuery` с ключом `['org-tree']`. TanStack Query передаёт `AbortSignal`: при размонтировании последнего потребителя незавершённый запрос отменяется.
2. `getOrgTree(signal)` → `fetchJson` (`fetch` с `Accept: application/json`, HTTP-ошибка → `ApiError`).
3. Ответ проверяется схемой `orgTreeResponseSchema` (zod). Невалидный ответ → `ApiValidationError`.
4. `buildOrgModel` нормализует массив в `OrgModel`: `nodes` по id, `childrenIds`, `rootIds`, глубина, и один раз считает агрегаты поддерева (`aggregate.ts`: суммарные численность и бюджет, средняя эффективность, взвешенная по численности). Дубли id, сироты и циклы → `OrgDataError`.
5. В кэше лежит готовая модель, а не сырой массив. Версия снапшота берётся из `ETag`.
6. `DashboardPage` ветвится по `status`: `pending` → skeleton, `error` → `ErrorState` с «Повторить», `success` с пустым `rootIds` → `EmptyState`, иначе `OrgTree`.

Кэш: `staleTime: 5 000 мс`. Повторное использование данных в пределах 5 с не создаёт запроса; после — фоновая ревалидация, старые данные остаются на экране, в шапке индикатор «обновляется…». `structuralSharing` сохраняет ссылки, если данные не изменились, поэтому потребители не перерисовываются.

Сообщения об ошибках для пользователя собирает одна функция `toUserMessage(error)`.

## Mock-сервер

`server/index.ts` — `node:http` без фреймворка, исполняется Node 24 напрямую. `GET /api/org-tree` отдаёт 52 узла (4 дивизиона × 3 отдела × 3 команды), сгенерированных детерминированно (seeded PRNG), с `ETag` = версия данных, `Cache-Control: no-cache` и 304 на совпавший `If-None-Match`. Переменная `MOCK_SCENARIO` воспроизводит состояния клиента; клиент о ней не знает.

В dev Vite проксирует `/api` и `/ws` на сервер, поэтому клиент ходит на относительные пути и не требует переменных окружения.

## Стили

styled-components. Токены — CSS-переменные в `createGlobalStyle` (светлая и тёмная тема по `prefers-color-scheme`), `theme` ссылается на них. Динамические пропсы — transient (`$tone`, `$expanded`) с конечным набором значений. Inline-стили не используются.
