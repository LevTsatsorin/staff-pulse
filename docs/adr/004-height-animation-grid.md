# ADR-004. Анимация раскрытия дерева через `grid-template-rows`

## Контекст

ТЗ требует анимировать раскрытие ветвей через изменение высоты, уважать `prefers-reduced-motion` и одновременно запрещает inline-CSS. Высота содержимого ветки заранее неизвестна. Свёрнутые узлы не должны получать фокус с клавиатуры.

## Решение

Обёртка `Collapsible` — `display: grid` с `grid-template-rows: 0fr` в свёрнутом и `1fr` в раскрытом состоянии и `transition: grid-template-rows 200ms`; внутренний блок — `min-height: 0; overflow: hidden`. Состояние переключает transient-проп, то есть класс styled-components. Дети ветки остаются смонтированными, свёрнутый блок получает атрибут `inert`. Глобальное правило `prefers-reduced-motion: reduce` отключает переходы. Прокрутка к выбранному узлу откладывается на длительность анимации, чтобы измерять уже раскрытую ветку.

## Альтернативы

- **Замер `scrollHeight` и `style.height` из JS.** Классический способ, но это inline-стиль, прямо запрещённый ТЗ, плюс замеры на каждое раскрытие.
- **`interpolate-size: allow-keywords` и `height: auto`.** Короче всего, но на момент решения поддерживается только в Chromium; годится как улучшение, а не как основа.
- **`max-height` с большим запасом.** Без JS, но скорость анимации зависит от запаса, а закрытие начинается с задержкой.
- **Размонтирование детей при сворачивании.** Меньше DOM, но анимировать исчезающий контент нечем.

## Последствия

- Нет ни одного атрибута `style` и ни одного замера DOM; анимация одинаково работает для веток любой высоты.
- Все узлы дерева всегда смонтированы (52 узла — несущественно); свёрнутые исключены из порядка Tab и дерева доступности через `inert`.
- Прокрутка к узлу, выбранному из таблицы, происходит после анимации раскрытия (задержка 200 мс).
