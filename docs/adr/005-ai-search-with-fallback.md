# ADR-005. AI-поиск: OpenAI со structured outputs и честный fallback

## Контекст

Бонусный этап ТЗ: строка поиска принимает естественный язык, ответ — структурированный фильтр на клиенте, при недоступности — текстовый поиск. Провайдер модели ТЗ не задаёт. У автора оплаченный доступ к OpenAI и нет ключа Anthropic. Ревьюер, скорее всего, запустит проект без ключа, поэтому fallback должен выглядеть намеренным, а не как поломка. Каждый вызов модели платный и занимает секунды.

## Решение

- **Сервер.** `POST /api/search/parse` вызывает OpenAI Responses API (`responses.parse`) с `zodTextFormat`: схема фильтра — та же zod-схема из `shared/search.ts`, по которой клиент проверяет ответ. Все поля обязательны и nullable, как требует strict-режим; неупомянутое условие — `null`. `reasoning.effort: "low"`, таймаут SDK 5 с без повторов. Ответы: 200 — фильтр; 400 — пустой или некорректный запрос; 502 — ошибка провайдера, отказ модели или ответ вне схемы; 503 — ключ не задан; 504 — таймаут. Ключ живёт только в окружении сервера.
- **Клиент.** Разбор запускается по Enter или кнопке, а не на каждое нажатие; поле при этом продолжает фильтровать по названию в реальном времени. `useMutation` отдаёт результат только последнего запроса. Успешный разбор очищает поле и показывает условия чипами; `sort` из ответа выставляет сортировку таблицы. Фильтр применяется чистой функцией поверх фильтра по названию и не трогает агрегаты.
- **Fallback.** Любая ошибка оставляет введённый текст фильтром по названию и показывает бейдж «AI недоступен». Ответ 503 запоминается до перезагрузки страницы: кнопка разбора неактивна, запросы не повторяются.
- **Модель.** По умолчанию `gpt-5.6-terra`, переключается `OPENAI_MODEL`. Выбрана замером на 18 запросах (числовые условия, уровни, сортировка, свободный текст, запрос не по теме), вызов тот же, что в сервере:

| Модель | Верно | p50 | p95 | $ за запрос |
|---|---|---|---|---|
| `gpt-5.6-luna` | 18/18 | 1.9 с | 3.2 с | 0.00014 |
| `gpt-5.6-terra` | 18/18 | 1.5 с | 2.5 с | 0.0014 |
| `gpt-5.6-sol` | 18/18 | 1.7 с | 4.8 с | 0.0027 |

Точность одинакова; `terra` быстрее всех и с лучшим запасом до таймаута, `sol` на p95 почти упирается в 5 с, `luna` в 10 раз дешевле, но медленнее. Для дашборда стоимость в десятые доли цента роли не играет.

## Альтернативы

- **Разбор на каждое нажатие** — платный запрос на каждую паузу в наборе и ожидание 1.5–2.5 с на недописанной фразе.
- **Разбор регулярками без модели** — не переносит разнообразие формулировок («топ дивизионов», «кто хуже всех работает»).

## Последствия

- Без ключа проект полностью работоспособен; AI-поиск деградирует до поиска по названию с понятным бейджем.
- Смена провайдера или модели — правка одного модуля или одной переменной окружения.
- Контракт фильтра один на сервер, клиент и модель; расхождение ключей сортировки ловит компилятор.
- Запрос стоит около $0.0014 и 1.5–2.5 с; лимит расходов задаётся в кабинете OpenAI.
